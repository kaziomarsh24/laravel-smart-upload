# Contributing to Laravel Smart Upload

Thank you for considering contributing to Laravel Smart Upload!

## Guidelines
- Follow PSR-12 coding standards.
- Write tests for any new features or bug fixes.
- Ensure all tests pass by running `composer test`.
- Keep individual classes modular and under 200 lines where possible.

## Pull Request Process
1. Fork the repo and create your branch from `main`.
2. Install dependencies with `composer install`.
3. Add your changes and tests.
4. Run `composer test` to ensure green tests.
5. Submit a pull request with a descriptive title and summary.
